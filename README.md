## Learning Path

A practical progression through this collection is:

1. Begin with **HTTP Hunt Unlocked** to practice application-level discovery.
2. Move to **Port Sleuth Service Trails** and **Nmap Night Recon** for network reconnaissance.
3. Continue with **Beacon Hunt 2** to expand service and environment discovery skills.
4. Practice **Lab Zero to Root** and **HackathonCTF 2: Enum to Root** for enumeration-focused CTF workflows.
5. Study **SUID Sleuth 5** for Linux security and SUID concepts.
6. Explore **BuffemR Breakout 2** and **BuffemR Bites: Overflow to Root** for buffer-overflow challenges.
7. Use **GDB Buffer Breakout** to build familiarity with debugging and binary analysis.
8. Finish with **BuffemR User Flag Hunt** and **SSH Pivot to Root** for practical CTF progression and SSH-related access workflows.

## How to Use the Labs

- Read the instructions for each lab before starting.
- Work only inside the authorized CTF or training environment.
- Keep notes about discovered services, ports, commands, and observations.
- For Nmap labs, understand the purpose of each scan rather than relying solely on automated results.
- For buffer-overflow labs, study the relationship between program behavior, memory, and debugging.
- For SUID and SSH exercises, document the security concepts demonstrated by the lab.
- Treat every flag as a learning objective and record how you reached it.
- Never test these techniques against systems without explicit authorization.
